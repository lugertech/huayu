# Example artwork / 示例插画

Original Huayu example artwork, created in November 2026. These fictional brands, stories, interfaces and teaching materials are provided under the repository’s MIT license. No third-party product screenshots or stock images are included here.

SVG files are the editable sources. Matching PNG files in `apps/web/public/examples/art/` were rendered in Chromium at the SVG’s intrinsic size, so the canvas examples can also be used with image-capable model services. Keep both language variants aligned when editing. The website uses the vector version for its lightweight previews; the app loads its bundled PNGs from stable local paths and includes them when exporting a project.

这些插画为画语原创示例，包含虚构品牌、故事场景、界面和教学图解，采用仓库的 MIT 许可。SVG 是可编辑源文件；`apps/web/public/examples/art/` 中的同名 PNG 由 Chromium 按原尺寸渲染，用于兼容模型图片输入。修改时请同步两种语言。完整作品内容在 `../catalog.json`，轻量展示摘要由 `scripts/generate-template-index.mjs` 生成。
