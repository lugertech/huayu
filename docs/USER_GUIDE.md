# 白板与作品

## 放入材料

新建项目后，可以绘图、输入文字、上传图片和文件。左侧组件栏可点击添加指令、网页、语音与图表，也可以把组件直接拖到画布中的目标位置。底部工具栏负责选择、手形、画笔、图形和原生连线。

组件栏固定在画布左侧，可以收起为图标。按住组件拖出后，完整卡片会跟随指针，松手放置；按 Esc 或拖回组件栏即可取消。每次放置都可以单步撤销。

画布占满内容区的高度。名称与保存状态在左上角，录屏、分享、导出与运行在右上角。

点击桌面侧栏右上角的收起按钮可以收起侧栏，点击顶部标志重新展开。图标始终保持原位，文字随侧栏展开显示。收起后，悬停或通过键盘聚焦图标可以查看名称；「最近项目」通过菜单打开，设置固定在底部。手机通过内容区左上角打开导航抽屉。

所有内容都在同一张无限画布中操作。打开旧的多页项目时，其他页面的材料会并入同一画布，内容、附件与连线继续保留。

鼠标停在卡片上时，也可以按住 Ctrl 使用滚轮缩放画布。文字较长时，普通滚轮仍用于滚动正文。

选中一份或多份素材后点击「继续创作」，检查素材列表，写下要求并提交。手绘、图形和画框作为整体画面提供给模型，已有文字与网页保留实际内容。录屏片段也可以成为带来源的普通文字素材。

没有模型密钥时也能打开、编辑和保存模板项目。文字类模板只需文本生成；图像与口播流程还需对应连接。可以先运行文字分支，配置齐全后再运行整张工作流。六份完整作品示例预置了作者编写的图文与网页，供查看、修改和继续创作；它们不代表某个模型的实测输出。

## 完整作品示例

模板库中标有「完整作品示例」的六个项目，打开后已有完整素材、创作指令、分支连接和可查看的作品。无需配置 Key，也能阅读文字、查看插画、操作网页原型，并编辑或导出项目。模型连接只在主动生成时需要。

- **松间咖啡**：11 个组件、16 条连接，从品牌与受众延展到两版海报、产品页和发布检查。
- **灯塔来信**：12 个组件、19 条连接，三幕故事逐章延续，分别配图，最后汇成阅读版和介绍页。
- **山野周末**：10 个组件、15 条连接，把真实任务需要的行程、规则与未决信息带入招募物料。
- **Flow**：10 个组件、14 条连接，从访谈原话走到需求、路径图和可操作看板。看板可添加任务、编辑标题、切换状态和筛选待回复；原型的修改仅保留在当前打开页面中。
- **城市热岛**：10 个组件、14 条连接，区分阅读材料、教学数据和结论限制，生成解释稿、知识图谱、信息图与自测题。
- **周五发布会**：11 个组件、17 条连接，保留转写时间戳，将决定、负责人待办、未决事项和跟进消息并列呈现。转写为编写的示例，没有附带真实录屏。

官网中点击示例可放大浏览流程、选择卡片，并在「内容与作品」「创作指令」之间切换。可交互的 Flow 网页可以直接操作。本地官网的「在画语中使用」会打开应用并定位到相应模板，点击模板后创建独立项目；公共部署的官网提供模板使用文档。

继续创作时，先修改左侧起始材料，再选择要更新的步骤。文字与网页使用文字连接；读取图片内容需要视觉理解连接，重新绘图需要图片生成连接。缺少连接会显示对应能力的配置提示，并保留已有示例作品。原四个快速开始和其余 14 个场景模板继续保留，已有项目不会被改写。

## 素材库

从左侧菜单进入「素材库」。左边是文件夹树，右边是当前目录的文件夹和图片；顶部的路径可以返回上一级。根目录显示未分组图片，搜索根目录时会查找全部分组。图片较多时向下滚动会继续加载。

- **整理分组**：点击「新建文件夹」。右键文件夹可以创建子文件夹、重命名或删除；也可以点击树中该文件夹旁的「…」。删除文件夹时，其中的图片和子文件夹移到上一级，不会删除图片。
- **移动图片**：直接把图片拖到左侧文件夹、右侧目录卡片或左侧「素材」根目录，目标位置会高亮。也可以右键图片，选择「移动到文件夹」。
- **查看与修改**：点击图片打开预览，可切换上一张和下一张、缩放、查看原始尺寸、旋转和重置。右键图片或点击「…」，可以重命名、下载原图或移入回收站。键盘可用 Shift＋F10 打开菜单、方向键选择、Esc 关闭。
- **批量上传**：点击「上传」，或将图片文件拖入当前目录或目标文件夹。检查上传列表，可取消单张或清空待上传项；点击「开始上传」后查看每张图片的结果。
- **恢复素材**：进入左下方的「回收站」，在图片菜单中选择「恢复素材」，回到原分组。已有画布中使用的图片不受移入回收站影响。

在画布中打开素材库，默认浏览全部图片，可通过顶部的分组筛选器、搜索和排序定位素材。单击选择图片，再点击「插入画布」，或双击图片直接插入；也可以拖到画布中的目标位置。图片作为原生图片插入，保留比例，并支持单步撤销。拖入画布会保留素材库中的原图片。从素材管理页插入时，可以选择已有画布或新建画布。

抽屉标题旁的「图形素材库」继续提供 Excalidraw 图形的保存与复用。图片文件与分类保存在本地运行数据目录；图形素材沿用当前浏览器的保存方式。

## 连接与执行

选中卡片后，从左右端口拖到其他卡片可以连接输入或后续步骤，拖到空白处可以接续新步骤。也可以点按端口或使用键盘打开菜单。连接方向表示内容流向；不允许的循环与重复连接会提示原因。

可以运行一个组件，也可以运行整张工作流。生成时查看状态和耗时，必要时停止。修改素材后，下游旧结果会提示需要更新；可以只更新受影响的分支。锁定结果会被继续复用。

## 多人协作

多人协作共用同一个画语服务和项目数据，不需要登录或配置模型密钥。每个人使用自己的浏览器打开同一份协作链接，即可共同编辑画布。

### 发起与加入

1. 打开要协作的画布，点击右上角「分享」。
2. 开启「允许通过链接协作」，点击「复制链接」。
3. 将链接交给能访问这台画语服务的协作者。协作者直接打开链接，无需导入项目或另建副本。
4. 新增、移动、修改和删除卡片后，对方页面会同步更新。等待画布名称旁显示「已保存」，再关闭页面。
5. 结束协作时，在原画布的「分享」中关闭开关。已打开的协作页面会显示「协作链接已关闭或失效」。重新开启后，请重新复制并发送新链接，旧链接不会恢复。

同一台电脑可用两个浏览器或两个标签页体验。其他电脑不能使用你链接中的 `127.0.0.1` 或 `localhost`：这些地址始终指向访问者自己的电脑。跨设备使用前，按 [局域网协作配置](./DEPLOYMENT.md#局域网协作) 启动服务，并先通过局域网地址打开原画布，再复制协作链接。

### 编辑、保存与恢复

- 分工编辑不同卡片可以保留彼此的修改。两人同时修改同一张卡片时，以最后被服务接收的保存为准，文字不会逐字合并；同一卡片建议轮流编辑。
- 缩放、平移和当前选择各自独立，不会把对方的视图拉走。当前没有成员列表、在线人数或其他人的鼠标指针。
- 出现「等待重连」时，未提交的编辑会暂存于当前浏览器。恢复连接后自动重试，也可以点击提示中的「重试」。等待「已保存」后再继续离开；未恢复前不要清除站点数据或改用另一个浏览器。
- 模型连接地址、密钥和模型选择不会随链接共享。需要执行 AI 步骤的人在自己的「设置 → 模型连接」中配置相应能力；其他人无需密钥也能编辑和查看已保存结果。一次工作流由一人运行，避免重复生成。

协作链接提供共同编辑，不提供只读访客、账号权限或项目隔离。能够访问这台画语服务的人也能打开项目列表；关闭协作链接只使该链接失效。请在可信范围内使用，部署与访问边界见 [部署与备份](./DEPLOYMENT.md)。

## 文字作品

打开「查看作品」后，以 Markdown 阅读正文。点击「编辑文字」修改生成内容，保存后再作为下一轮输入；原始创作要求保持可查看。关闭窗口前未保存的文字会保留为当前浏览器草稿，重新打开可继续。

如果原文在其他页面更新，界面会提示冲突并保留草稿，避免静默覆盖。保存前先核对当前作品；也可以放弃草稿回到当前已保存内容。

## 图片作品

点击图片进入查看，可以缩放、回到原始尺寸或适应窗口，放大后拖动检查细节。「裁剪与旋转」可以选择保留范围和调整方向，保存为新图片，原图继续保留。

复制写入实际图片；下载保存图片文件。继续生成时可以描述需要改变和保留的细节，并选择服务支持的图片比例。裁剪编辑需要先保存，再生成下一版。

## 网页作品

网页可以直接交互预览，也可以切换桌面与手机尺寸。点击「编辑 HTML」修改代码；宽屏同时显示实时预览，小屏可切回预览检查效果。

「保存并创作」会先保存手工修改，再将修改后的网页用于下一版。下载得到 HTML 文件。预览限制访问父页面、网络请求与表单提交，部分依赖外部脚本、在线字体或远程接口的网页可能无法完整运行。

## 新方向与版本

在作品旁写下修改要求，默认生成相同类型的新版本，也可以把文字、图片和网页互相转化。新方向会作为相连分支保留，完成后自动进入新作品。通过上一版按钮或版本列表找回之前的方向。

生成失败或主动停止后，可以修改要求并继续未完成步骤。关闭作品窗口不会取消正在生成的请求，再次打开可以查看进度。刷新浏览器会终止当前模型请求，但保留已保存作品与草稿；重新打开后继续生成。

版本列表记录主动派生的作品，不记录每次文字修改的历史快照。常规手工修改仍通过撤销与重做处理。

## 导出与导入

| 格式 | 适合用途 |
| --- | --- |
| `.huayu.json` | 完整画布与附件，可继续编辑 |
| PNG / SVG | 分享当前画面，不保留完整编辑结构 |
| `.excalidraw` | 整个画布及图片，AI 卡片包含快照与可恢复数据 |
| Markdown / HTML / 图片 | 单份作品，在其他工具中继续使用 |

从项目首页导入项目文件或兼容的 Excalidraw、历史 tldraw JSON。导入前保留原文件；不支持的第三方扩展字段可能无法还原为相同交互。

模型连接不会随项目导出；在其他浏览器或端口使用时需要重新配置。
