# 白板与作品

## 放入材料

新建项目后，可以绘图、输入文字、上传图片和文件。左侧组件栏可点击添加指令、网页、语音与图表，也可以把组件直接拖到画布中的目标位置。底部工具栏负责选择、手形、画笔、图形和原生连线。

组件栏位于画布左侧，默认只显示图标。鼠标移入时展开名称，移开后收起；使用键盘聚焦组件时也会展开名称。按住组件拖出后，完整卡片会跟随指针，松手放置；按 Esc 或拖回组件栏即可取消。每次放置都可以单步撤销。

画布占满内容区的高度。左上角的返回箭头可直接回到项目列表，悬停显示操作说明；画布名称位于箭头右侧。编辑在后台自动保存，正常状态不显示保存文字；仅在连接或保存异常时于右下角提示，并提供重试。右上角提供在线成员与邀请，以及录屏、导出和白板菜单。悬停图标可查看操作名称。窄窗口下工具区分行排列。

在任意节点上点击运行，即可从这个节点开始，按连线顺序执行后续步骤。运行时，节点显示进度，点击节点上的停止按钮可停止本次运行。

文本组件收到前置输出后会替换正文。图片、语音、网站、文件和图表通过前置组件接收生成内容；网站在组件内预览生成的网页。音频上传后立即转写，文档上传后立即解析。连入「运行」节点的执行链会停在该节点，点击后再继续；后续组件仍可读取它前面的材料。

点击桌面侧栏右上角的收起按钮可以收起侧栏，点击顶部标志重新展开。图标始终保持原位，文字随侧栏展开显示。收起后，悬停或通过键盘聚焦图标可以查看名称；「最近项目」通过菜单打开，设置固定在底部。手机通过内容区左上角打开导航抽屉。

所有内容都在同一张无限画布中操作。打开旧的多页项目时，其他页面的材料会并入同一画布，内容、附件与连线继续保留。

鼠标停在卡片上时，也可以按住 Ctrl 使用滚轮缩放画布。文字较长时，普通滚轮仍用于滚动正文。

通过连线把素材接到需要运行的组件，在指令组件中填写要求。图片上传／下载、图片比例、联网搜索、语音和文件操作、网页工具与图表类型选择常驻组件内部，与旧版的位置一致。文本组件不显示额外工具条。录屏片段也可以成为带来源的普通文字素材。

### 白板菜单与常用快捷键

- 右上角图标工具组末尾的「白板菜单」提供导入、导出、查找、快捷命令、帮助、外观和画布背景设置。
- 选择图形或绘图工具后，可在画布右侧调整描边、填充和线条样式。宽屏显示完整面板；窄桌面和平板显示紧凑图标栏，点击图标展开对应设置，点击画布或按 Esc 收起。长面板可以滚动。手机通过底部样式按钮展开设置，关闭后恢复组件栏和绘图工具。
- 点击左下角的缩放百分比可打开缩放菜单，恢复至 100%、显示全部内容或聚焦选中内容。
- 选中图形或点击卡片标题后，按 **Delete / Backspace** 删除；Mac 键盘上的 **⌫** 对应 Backspace。
- **Cmd / Ctrl + C、X、V** 复制、剪切和粘贴选中内容；**Cmd / Ctrl + D** 直接创建副本。卡片和原生图形可以一起选择、复制到另一张画布，副本保留内容，连线与分组由白板处理。
- **Cmd / Ctrl + Z** 撤销，**Cmd / Ctrl + Shift + Z** 重做。文字输入框内的删除键只编辑文字，不删除整张卡片。
- 在卡片标题、边框或图片区域右键可打开白板原生菜单；文本框和阅读区域保留浏览器的文字菜单。文字输入框中的复制、粘贴、全选和撤销只作用于文字。
- 右键「复制为 PNG / SVG」会包含卡片实际内容；**Alt / Option + Shift + C** 复制为 PNG。通过右键菜单锁定卡片后，卡片内容与控件也会锁定，可从右键菜单解锁。
- 选中卡片后按 **Enter** 或双击卡片标题可打开内容。原生图形、文字和图片保留白板自身的编辑与裁剪交互。
- 画布获得焦点时，**Cmd / Ctrl + A** 全选，**Cmd / Ctrl + G** 分组，**Cmd / Ctrl + Shift + G** 取消分组，方向键移动元素，**Cmd / Ctrl + K** 编辑元素链接。侧栏中的搜索图标仍可打开项目查找。
- 「白板菜单 → 帮助」或右下角的帮助按钮可查看完整快捷键。

## 完整作品示例

模板库中标有「完整作品示例」的六个项目，打开后已有完整素材、创作指令、分支连接和可查看的作品。无需配置 Key，也能阅读文字、查看插画、操作网页原型，并编辑或导出项目。模型连接只在主动生成时需要。

- **松间咖啡**：11 个组件、16 条连接，从品牌与受众延展到两版海报、产品页和发布检查。
- **灯塔来信**：12 个组件、19 条连接，三幕故事逐章延续，分别配图，最后汇成阅读版和介绍页。
- **山野周末**：10 个组件、15 条连接，把真实任务需要的行程、规则与未决信息带入招募物料。
- **Flow**：10 个组件、14 条连接，从访谈原话走到需求、路径图和可操作看板。看板可添加任务、编辑标题、切换状态和筛选待回复；原型的修改仅保留在当前打开页面中。
- **城市热岛**：10 个组件、14 条连接，区分阅读材料、教学数据和结论限制，生成解释稿、知识图谱、信息图与自测题。
- **周五发布会**：11 个组件、17 条连接，保留转写时间戳，将决定、负责人待办、未决事项和跟进消息并列呈现。转写为编写的示例，没有附带真实录屏。

官网中点击示例可放大浏览流程、选择卡片，并在「内容与作品」「创作指令」之间切换。可交互的 Flow 网页可以直接操作。本地官网的「在画语中使用」会打开应用并定位到相应模板，点击模板后创建独立项目；公共部署的官网提供模板使用文档。

继续创作时，先修改左侧起始材料，再选择要更新的步骤。文字与网页使用文字连接；读取图片内容需要视觉理解连接，重新绘图需要图片生成连接。缺少连接会显示对应能力的配置提示，并保留已有示例作品。原四个快速开始和其余 14 个场景模板继续保留，已有项目不会被改写。

## 资料库

从左侧菜单进入「资料库」（`/library`），浏览各项目「项目附件」中的图片、文件和语音音频。

- **查找资料**：搜索资料名称、项目名称或文字摘要；使用类型和项目筛选器缩小范围。
- **调整视图**：切换列表或网格；在「查看选项」中切换「按项目分组」，或调整排序。分组默认显示部分条目，点击「显示更多」展开。
- 点击附件打开**预览**，查看文件正文和图片，或播放语音音频。通过「…」**下载**附件。
- **回到项目**：点击「在项目中查看」定位到原画布中的对应内容。资料的编辑和移除在原项目中完成。

资料库默认平铺展示附件，不按项目分组。可在「查看选项」中开启「按项目分组」，下次打开时会保留所选方式。

资料库展示项目当前的附件。项目改名、附件替换或组件移除后，返回资料库即可看到变化；删除项目也会移除它在资料库中的条目。在其他窗口编辑后，可返回此窗口或点击刷新查看最新内容。

## 素材库

素材库独立管理用户上传的常用文件，不关联任何项目。当前已隐藏侧边栏入口，可通过应用的 `/assets` 页面访问。它不会自动收集项目内容，也不提供选择画布或插入项目的操作。

- **整理文件夹**：左侧是文件夹树，右侧是当前目录内容。新建、重命名或删除文件夹时，已有文件不会被删除；删除文件夹会将内容移到上一级。
- **移动文件**：将文件拖到文件夹或「素材」根目录；也可以使用「…」中的「移动到文件夹」。
- **查看与修改**：图片可预览，其他文件可下载查看。文件菜单支持重命名、下载、移动和移入回收站。
- **批量上传**：点击「上传」或拖入文件，检查队列后点击「开始上传」。支持图片、文档、音视频等文件。
- **恢复文件**：在「回收站」中选择恢复。删除项目不会影响素材库文件。

## 连接与执行

选中卡片后，从左右端口拖到其他卡片可以连接输入或后续步骤，拖到空白处可以接续新步骤。也可以点按端口或使用键盘打开菜单。连接方向表示内容流向；不允许的循环与重复连接会提示原因。

可以运行一个组件，也可以运行整张工作流。生成时查看状态和耗时，必要时停止。修改素材后，下游旧结果会提示需要更新；可以只更新受影响的分支。锁定结果会被继续复用。

## 多人协作

多人协作共用同一个画语服务和项目数据，不需要登录或配置模型密钥。每个人使用自己的浏览器打开同一份协作链接，即可共同编辑画布。

### 发起与加入

1. 打开要协作的画布，点击画布右上角的「邀请」。
2. 开启「允许通过链接协作」，点击「复制链接」。
3. 将链接交给能访问这台画语服务的协作者。协作者直接打开链接，无需导入项目或另建副本。
4. 绘制中的笔迹、形状变化及卡片的新增、移动、修改和删除会实时出现在对方画布上，同时显示协作者的鼠标和选框。编辑会自动保存，无需手动点击保存按钮。
5. 结束协作时，在原画布的「邀请」弹窗中关闭开关。已打开的协作页面会显示「协作链接已关闭或失效」。重新开启后，请重新复制并发送新链接，旧链接不会恢复。

同一台电脑可用两个浏览器或两个标签页体验。其他电脑不能使用你链接中的 `127.0.0.1` 或 `localhost`：这些地址始终指向访问者自己的电脑。跨设备使用前，按 [局域网协作配置](./DEPLOYMENT.md#局域网协作) 启动服务，并先通过局域网地址打开原画布，再复制协作链接。

### 在线成员与移出协作

- 每个房间最多同时容纳 **15 位协作者**，房主不占名额。同一浏览器的多个标签页合并为一位成员；不同浏览器或浏览器配置文件分别计数。
- 右上角显示重叠头像，超过三位时用「+N」表示其余人数。点击头像组可查看完整在线名单，房主和自己有单独标识；头像颜色与协作者光标对应。匿名协作使用颜色和短标识，不要求账号或上传头像。
- 房主在名单中点击成员右侧的「⋯ → 移出协作」，确认后立即断开该成员的所有标签页连接，清除其光标和选框并释放名额。已保存的画布内容保留，其他成员继续协作。协作者看不到移除和邀请管理入口。
- 满员时，新加入者会看到原因，可在有空位后点击「重新加入」。被移出者会看到独立提示，页面不会自动重连，也不能继续保存或请求当前画布的附件。
- 成员身份由当前浏览器保留。移除结果在服务重启后仍生效，但不等同于账号封禁：清除站点数据、身份过期或更换浏览器后，持有有效邀请链接的人仍可作为新成员加入。若需让原链接彻底失效，请关闭协作后重新开启，并仅向需要的成员发送新链接。

### 编辑、保存与恢复

- 分工编辑不同卡片可以保留彼此的修改。两人同时修改同一张卡片时，以最后被服务接收的保存为准，文字不会逐字合并；同一卡片建议轮流编辑。
- 缩放、平移和当前选择各自独立，不会把对方的视图拉走。可以看到带颜色的匿名协作者光标和选框；对方选中的内容不会成为自己的选择，远端修改也不会进入自己的撤销记录。指针移出画布或切换窗口时隐藏鼠标，关闭画布或断开连接后移除该协作者的显示。
- 实时预览与自动保存分开进行。看到对方正在绘制不代表内容已经保存，内容会在后台自动提交；若存在连接或保存异常提示，请先处理提示再离开。鼠标位置、选区和在线状态不写入项目、模板或导出文件。
- 出现连接中断提示时，未提交的编辑会暂存于当前浏览器。恢复连接后自动重试，也可以点击提示中的「重试」。异常提示消失后再离开；未恢复前不要清除站点数据或改用另一个浏览器。
- 模型连接地址、密钥和模型选择不会随链接共享。需要执行 AI 步骤的人在自己的「设置 → 模型连接」中配置相应能力；其他人无需密钥也能编辑和查看已保存结果。一次工作流由一人运行，避免重复生成。

### 协作者的界面和权限

协作者打开链接后直接进入独立画布界面，不显示工作区侧栏、最近项目、全局搜索、资料库、全局素材库和录屏管理；画布名称为不可修改的文字，不提供改名、分享管理或发布模板入口。

| 操作 | 本机管理端 | 协作者 |
| --- | --- | --- |
| 查看、绘制、编辑卡片及连线 | 可以 | 仅当前画布 |
| 查看结果、导出画布 | 可以 | 仅当前画布 |
| 上传、下载附件 | 可以 | 仅当前画布附件 |
| 配置和使用 AI 模型 | 自己的浏览器 | 自己的浏览器 |
| 浏览项目、资料库、全局素材库和录屏 | 可以 | 不提供入口，接口拒绝访问 |
| 改名、删除项目、管理分享、发布模板、移出成员 | 可以 | 不提供入口，接口拒绝访问 |

权限由服务端校验，修改项目地址或直接调用接口不会扩大协作链接的范围。关闭协作会撤销对应链接及附件访问。管理端基于服务机器的连接来源识别，不是账号系统；在该机器上直接打开工作区仍有管理权限。部署边界见 [部署与备份](./DEPLOYMENT.md)。

## 文字作品

双击文本组件标题，或选中组件后按 Enter，以 Markdown 阅读正文。点击「编辑文字」修改生成内容，保存后再作为下一轮输入；原始创作要求保持可查看。关闭窗口前未保存的文字会保留为当前浏览器草稿，重新打开可继续。

如果原文在其他页面更新，界面会提示冲突并保留草稿，避免静默覆盖。保存前先核对当前作品；也可以放弃草稿回到当前已保存内容。

## 图片作品

点击图片进入查看，可以缩放、回到原始尺寸或适应窗口，放大后拖动检查细节。「裁剪与旋转」可以选择保留范围和调整方向，保存为新图片，原图继续保留。

复制写入实际图片；下载保存图片文件。

## 网页作品

网页可以直接交互预览，也可以切换桌面与手机尺寸。点击「编辑 HTML」修改代码；宽屏同时显示实时预览，小屏可切回预览检查效果。

下载得到 HTML 文件。预览限制访问父页面、网络请求与表单提交，部分依赖外部脚本、在线字体或远程接口的网页可能无法完整运行。

## 版本与撤销

已有作品可以通过上一版按钮或版本列表查看。图片裁剪与旋转保存为新图片，原图继续保留。文字和 HTML 的手工修改通过撤销与重做处理。

## 导出与导入

| 格式 | 适合用途 |
| --- | --- |
| `.huayu.json` | 完整画布与附件，可继续编辑 |
| PNG / SVG | 分享当前画面，不保留完整编辑结构 |
| `.excalidraw` | 整个画布及图片，AI 卡片包含快照与可恢复数据 |
| Markdown / HTML / 图片 | 单份作品，在其他工具中继续使用 |

从项目首页导入项目文件或兼容的 Excalidraw、历史 tldraw JSON。导入前保留原文件；不支持的第三方扩展字段可能无法还原为相同交互。

项目文件导入和 `.huayu.json` 完整项目导出的上限均为 128 MiB。超限导出会提示并停止生成文件；请先拆分内容再重试。

模型连接不会随项目导出；在其他浏览器或端口使用时需要重新配置。
