# 架构与迁移范围

## 目录

```text
apps/
  site/                 React 静态介绍页与文档，构建时预渲染为 HTML
  web/                  React、Vite、shadcn/ui（Base UI）、Excalidraw、React Flow
    src/ai/             浏览器模型连接、调用和从原后端移入的提示词
    src/canvas/         画布界面、本地恢复、记录同步、导入导出与示例
      engine/           自有记录存储、几何、兼容读取和卡片快照导出
      excalidraw/       原生场景转换、交互、组件覆盖层和本地字体
    src/i18n/           界面语言检测、浏览器偏好与英文文案
    src/workflow/       工作流依赖规划与执行
    src/recording/      录制、音轨处理、转写与分析任务
    src/ui/             shadcn Base UI 组件源码
  api-rust/
    crates/huayu-core/  无 I/O 的业务类型、文档记录校验与合并
    crates/huayu-store/ SQLite、SeaORM entity 与版本迁移
    crates/huayu-server/ Axum 路由、文件处理、WebSocket 与启动
scripts/                本地开发、Cargo 入口、安全与发布检查、Git 源码归档和依赖许可生成
templates/              双语模板内容与生成的轻量索引
var/dev/                运行数据，Git 忽略
```

Rust API 参考 timetable `apps/api-rust` 的 workspace、薄二进制入口、业务模块、extractor、错误响应和代码样式。具体样式保存在 [CODE_STYLE.md](../apps/api-rust/CODE_STYLE.md)。本项目使用独立 SQLite 数据库，不连接 timetable 或原项目的数据库。

## 迁移边界

`templates/catalog.json` 是新增 20 个内置模板的共享目录，包含中英文素材、指令与图连接。Rust 在启动时按 ID 增量补充模板元数据，前端在创建项目时按当前语言实例化画布，轻量模板使用透明流程封面，六个完整作品示例使用对应原创作品封面；原有模板、使用次数和项目内容不被覆盖。模板没有模型地址、密钥或模型选择。

项目列表只加载 `templates/index.json` 中的元数据与本地封面地址；流程封面由目录预先生成，完整素材、指令与作品随画布模块按需加载。官网使用 `templates/showcase.json` 中的六份展示摘要，点开示例后才加载完整内容。原创 SVG 保存在 `templates/art/`，同包的 PNG 用于画布图片与模型参考输入。修改目录后运行 `node scripts/generate-template-index.ts` 更新两份索引与流程封面，再运行格式化；Web 构建会检查生成物是否一致。

MenteX 的 AI 节点、连接点及图表编辑器保留并适配主题。原 tldraw 依赖由 MIT 许可的 Excalidraw 替换。保留应用记录模型兼容旧项目，双向转换原生图形、箭头绑定、分组、页面和图片；原生扩展字段、压感和路径保存在记录中。React 组件覆盖在原生几何上，几何选择、拖动、缩放、绑定和历史操作由 Excalidraw 管理，不生成内部嵌入链接。执行流程统一到 `workflow`，避免事件递归导致循环调用或重复运行。tpk-admin 的 MenteX 业务迁移到 Rust；提示词和模型编排移动到前端。

| 原模块 | 新实现 |
| --- | --- |
| NestJS 项目代理、Laravel 项目存储 | Rust 项目接口与 SQLite |
| tldraw 云房间/原鉴权同步 | 本地记录补丁与 Axum WebSocket |
| Laravel 模板、标签与复制 | 本地模板库与 24 个内置模板 |
| 指令、图片、音频、网页、图表、文件生成 | 浏览器 OpenAI 兼容客户端及原业务提示词 |
| 云文件上传、OSS/COS 附件 | UUID 命名的本地附件文件 |
| 云文档解析 | Rust 本地文本、PDF、DOCX、工作簿解析 |
| 云录屏与服务端分析队列 | 浏览器录制、本地 FFmpeg 分段解码、浏览器模型请求及可继续的本地检查点 |
| 登录、用户、会员、积分、充值、支付 | 移除 |
| tpk-admin 中与 MenteX 无关的教育管理模块 | 不引入新项目 |

原云数据库中的项目、模板和录屏不在源码仓库中，因此不会自动出现在新实例。可通过兼容的项目 JSON 导入已有画布；不访问或迁移原生产数据库。

## 保存与并发

前端只同步 `document`、`page`、`shape`、`binding`、`asset` 文档记录。会话状态和模型设置不进入文档接口。修改先写入 IndexedDB 日志，再合并为批量记录补丁提交到本地 API。提交失败时保留日志；重载后用日志覆盖已保存文档，并在连接恢复后重试。

服务端串行处理本实例的文档修改，按记录合并补丁并更新修订号。不同记录的并发编辑会保留；同一记录的并发修改以服务端最后收到的补丁为准。WebSocket 广播补丁和初始快照，落后客户端重新获取快照。这不是 tldraw Sync 的 CRDT 协议，不依赖 Node 同步服务。

尚未确认的本地修改暂时覆盖对应远端记录；保存确认后，客户端按修订号补回更晚收到的远端修改或删除，继续保护尚未提交的新编辑。原生画布捕获一次本地撤销记录前，会先以非历史更新对齐未参与本次修改的元素，避免初次编辑时的适配元数据进入其他卡片的撤销记录。

协作页面携带当前链接令牌访问项目、补丁和 WebSocket。关闭链接会通知并断开协作页面，后续旧链接请求被拒绝；本机原项目页面仍可编辑。实例没有用户或租户隔离，链接令牌不构成项目列表的访问控制。

工作流规划在执行前检查可达子图的循环。可并行的同层节点同时运行，汇合节点等待可达父节点完成。停止操作通过 `AbortController` 取消模型请求，并在取消后阻止结果覆盖画布。

## 数据边界

模型调用在浏览器内使用官方 `openai` TypeScript SDK（Apache-2.0）处理请求与流式响应，继续连接用户填写的 OpenAI 兼容服务。每次按所需能力检查连接；默认远程地址与模型名不视为已配置。本机免密服务不会发送占位认证头，传输层移除 SDK 的附加诊断头，以兼容只放行标准请求头的 CORS 服务。连接测试最多 15 秒，普通生成 180 秒、图片生成 300 秒；计时覆盖读取响应，用户取消独立保留，自动重试关闭。网络和服务错误统一转换为本地化提示，不将原始错误正文或密钥写进界面。

- 模型连接仅由浏览器读取和保存，服务端没有对应类型或配置接口。
- 模型输出的网页在不授予同源权限的 iframe 中预览，全屏预览保持同样隔离。
- 文件使用服务端生成的 UUID 路径；客户端文件名不参与路径拼接。
- 本地 API 验证 Host 与 Origin，不开放任意跨来源请求。
- 网页元信息读取限制地址协议、解析后的目标地址、重定向次数、时间和响应大小。
- 接口返回业务错误；数据库及文件内部诊断仅进入本地日志。

## 画布与许可

`CanvasStore` 维护完整文档记录，批量操作在成功后统一发出修改事件；失败的命令回滚。所有操作在单一画布内完成，远端更新不加入本机撤销栈。应用记录历史用于命令的原子执行和回滚。相机与选择仅进入本机 IndexedDB。历史页面记录继续兼容读取，打开多页项目时会保留内容和相对布局，将材料整理到同一画布，并通过普通文档补丁保存；生成结果的新鲜度随布局迁移更新，已有过期状态继续保留。

Excalidraw 提供原生绘图、视口、选择、拖拽、调整大小、箭头绑定、分组和撤销重做。AI 卡片使用同一坐标与变换，输入框直接编辑，卡片标题可拖动。左侧组件栏支持点击与拖拽创建，卡片中的修改键滚轮继续交给白板缩放。图表编辑器继续使用 React Flow。原生元素通过 Excalidraw 导出；AI 卡片先生成本地高清快照，再组合到 PNG、SVG 和原生文件中。图片与字体在本机打包，不依赖字体 CDN。完整项目和附件使用 `.huayu.json`，`.excalidraw` 保留画布、图片、卡片快照及可恢复内容。

应用代码和自有画布层采用 MIT；Excalidraw 和 React Flow 均采用 MIT，无生产许可证密钥要求。仓库不包含 tldraw SDK、资产包、许可校验或试用服务。第三方字体和其他运行依赖继续遵守各自许可。许可清单见 [DEPENDENCY_LICENSES.md](./DEPENDENCY_LICENSES.md)。

## 录屏分析

`media.rs` 只读取 UUID 对应的本地附件，限制媒体格式和文件协议；音轨单次最长五分钟，最多两个并行解码进程。模型连接和密钥不参与这些接口。没有 FFmpeg 时前端回退浏览器解码。

`recording/analysis.ts` 把每段语音识别结果立即保存；对长转写分批整理，再合并内容记录、章节和原文问答。检查点记录来源附件、已完成段数、转写指纹及已完成的报告片段。重新打开后可继续；报告失败不覆盖上一次可读报告。校对转写会清除旧报告，避免文字与分析结果不一致。

## 中英文

应用通过浏览器语言状态订阅更新界面，不重新挂载画布与作品编辑器。语言选择只保存于浏览器，和模型连接分别管理。状态判断使用固定标识，文案通过翻译与命名插值显示；日期和数字使用当前语言格式。已知接口错误在前端边界本地化，不修改接口的数据约定。

内置示例的展示信息与新建素材使用当前语言，已有名称、提示词、作品和转写不批量改写。模型提示词提供中英文版本，长录屏任务维持开始时的输出语言，进度文案仍可即时切换。官网将中文与 `/en/` 英文指南分别预渲染，链接和页面信息保持对应语言。
