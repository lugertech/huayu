# 常见问题

## 页面能打开，但读取项目失败

确认 Rust 服务正在运行，检查 `http://127.0.0.1:5858/api/health` 是否返回 `status: ok`。开发模式需要同时启动前端与 API；关闭一个进程会影响使用。端口被占用时先确认占用者，避免停止无关程序。

## 模型无法连接

核对模型服务是否启动、API 根地址、实际模型名称和对应能力。浏览器需要能直接访问该服务，并且服务允许当前页面来源。使用本机服务时密钥可以留空，其他服务按供应商要求配置。参见 [模型连接](./MODEL_SETUP.md)。

## 同一个模型地址，换端口后配置消失

浏览器按来源分别保存设置。`localhost`、`127.0.0.1` 和不同端口都可能有不同存储；回到原地址，或在新来源重新配置。不要通过导出浏览器存储来分享连接密钥。

## 录屏没有声音或不能共享系统声音

先检查原视频是否有音轨，再检查浏览器共享面板是否允许所选来源的声音，以及麦克风是否授权。系统声音的支持取决于系统、浏览器和共享来源；可以改用带声音的标签页，或者导入已录好的音视频。

## 录屏按钮不可用

使用支持 `getDisplayMedia` 和 `MediaRecorder` 的桌面浏览器，并从本机来源或 HTTPS 打开。检查操作系统的屏幕录制权限，授权变化后可能需要重新启动浏览器。手机通常不能执行桌面屏幕采集，可以导入录屏后回看与分析。

## 逐句时间或发言人不准确

它们来自识别服务。仅文字格式不能提供准确逐句时间；不同识别模型的发言人能力也不同。先核对音轨和识别配置，再校对文字。画语不会根据普通段落伪造逐句时间。

## 长视频分析失败

确认 FFmpeg 和 ffprobe 在 PATH 中，文件不超过 512 MB。查看具体错误并继续已完成分段；识别服务也可能有单次大小、时长或速率限制。没有本地解码器时，浏览器回退会占用更多内存。

## 浏览器关闭后作品没有保存

画布在后台自动保存；右下角出现异常提示时，修改可能仍仅保留为浏览器草稿，尚未提交到项目。服务不可达时，先恢复本地服务并等待提交；不要清除站点数据。未保存录屏应先下载或保存，刷新不能恢复内存中的录制。

## 首页缩略图暂时未更新

打开对应画布后等待资源读取和保存。预览会核对文档版本并重新生成；附件缺失时先恢复附件。封面更新不改变作品的编辑时间。

## 协作者打不开链接或看不到更新

先确认双方访问同一台画语服务。发给其他电脑的链接不能使用 `127.0.0.1` 或 `localhost`；按 [局域网协作](./DEPLOYMENT.md#局域网协作) 使用服务电脑的实际 IP，并核对服务端口和防火墙。显示「协作链接已关闭或失效」时，请发起人重新开启分享并发送新链接。

若右下角显示连接中断提示，先恢复连接，必要时点击「重试」，等待提示消失；不要清除浏览器数据。反向代理需支持 `/api/projects/*/events` 的 WebSocket 升级。两人同时编辑同一卡片时保留最后保存的内容，不进行逐字合并，建议分别编辑不同卡片。完整步骤见 [多人协作](./USER_GUIDE.md#多人协作)。

## 网页预览与独立浏览器不同

预览运行在隔离环境中，限制外部脚本、网络请求、字体和表单提交。优先生成自包含网页。可下载 HTML 在适当环境检查；不要为了预览向网页写入模型密钥。

## PDF 不能提取文字

本地解析主要读取已有文本，扫描件需要先 OCR。过大的文件或受密码保护的文档也可能无法解析。请保留原文件并使用已脱敏的小文件复现。

## 如何反馈问题

提供版本、系统、浏览器、最短复现和脱敏错误。不要附 API 密钥、私人录屏、完整浏览器存储或未经许可的项目。安全问题按根目录 `SECURITY.md` 处理。
