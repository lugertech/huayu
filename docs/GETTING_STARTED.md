# 快速开始

画语把素材、生成结果和后续修改放在同一张画布上。你可以从一个主题开始写作，用一张图片继续创作，也可以把录屏中的一句话变成新的素材。

## 安装与启动

先按 [Vite+ 安装指南](https://viteplus.dev/guide/) 安装 `vp`，并准备 Node.js 22.18 或更高的 22.x 版本、24.11 或更高的 24.x 版本，或 Node.js 26 及以上版本，以及 Rust 1.95。项目使用 Vite+ 1.5.0，`vp install` 会使用锁定的 pnpm 12.11.2。Windows 建议使用 Git Bash 执行仓库中的命令。录屏长音轨处理建议安装 FFmpeg 与 ffprobe，并确认它们位于 PATH 中。

先确认 `vp --version`、`node --version`、`rustc --version` 与 `cargo --version` 可用。需要安装 Rust 时使用 [Rust 官方安装说明](https://www.rust-lang.org/tools/install)。已有工具链放在独立目录时，可按根目录 README 在 `.env` 中设置 `HUAYU_RUST_TOOLCHAIN_DIR`；该目录包含 `.cargo/` 和 `.rustup/`，无需把本机路径写进源码。

取得项目源码并进入根目录后执行：

```sh
vp install --frozen-lockfile
vp run dev
```

打开 [本地画语](http://127.0.0.1:5173)。首次启动会创建本地数据库，不需要云存储或额外数据库。开发时 5173 是界面，5858 是数据服务；两个进程需要同时运行。

需要使用构建后的版本时：

```sh
vp run build
vp run start
```

然后打开 [构建后的画语](http://127.0.0.1:5858)。首次 Rust 编译与安装依赖需要联网下载；已经构建后，普通白板编辑不需要连接模型服务。

## 界面语言

应用与官网支持简体中文和 English。首次访问按浏览器首选语言匹配，不支持的语言回退英文。在「设置 → 通用 → 语言」中手动选择后，偏好保存在当前浏览器；「跟随浏览器」恢复自动检测。官网页首也提供语言入口，英文文档可直接访问。不同来源与端口的偏好独立保存。已有项目名称、提示词、转写及作品内容不会被自动翻译。

## 完成第一次创作

1. 在项目页选择写作示例，或者新建空白项目并添加文字素材。
2. 在「设置 → 模型连接」中配置文本生成服务。服务地址填写 API 根地址，例如 `http://localhost:11434/v1`；模型名称需要与服务实际提供的名称一致。
3. 回到画布，添加创作指令组件，写下要求，并将文字素材连到指令组件。
4. 点击指令组件右上角的运行按钮。生成结果会显示在相连的文本组件中。

生成步骤与素材通过连线相连。停止或生成失败后，可以在节点上修改要求并重新运行。

## 先不用模型

未配置模型时也可以绘图、整理文字、导入图片、编辑已有作品和导出项目。AI 生成、识别与分析需要对应模型服务。不同能力可以分开配置，详见 [模型连接](./MODEL_SETUP.md)。

## 保存你的作品

画布在后台自动保存到本机，无需手动保存，也不常驻显示保存状态。连接中断或保存异常时，右下角会提示并提供重试；请处理异常后再关闭页面或停止服务。

通过「导出 → 导出项目文件」保存完整 `.huayu.json`，其中包含整个画布和附件；PNG、SVG 更适合分享画面。仅导出图片不能替代完整项目备份。完整备份与恢复方法见 [部署与备份](./DEPLOYMENT.md)。
