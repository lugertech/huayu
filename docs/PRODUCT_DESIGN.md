# 从 tldraw computer 到画语：产品判断与实现

调研与实现日期：2026-10-24。

## 产品应该成为什么

画语适合成为一个把资料、草图和录屏转化为作品的本地创作工作台。它的核心过程应该是：放入材料，指明意图，看到结果，直接修改，再沿着结果继续。白板提供思考和操作的空间，连接线表达材料之间的依赖，录屏提供可以回溯的事实来源。

现有项目已经具备文字、图片、网页、语音、文件、图表、绘图和录屏分析能力。当前更需要打磨这些能力之间的衔接，让一个实际任务能够顺畅完成。单纯增加组件类型，会加重学习负担。

## 本轮已经落实

### 1. 从选区直接开始创作

选中一份或多份材料后，工具栏上方出现「继续创作」。已有文字、图像、网页和生成结果的卡片也提供同样入口。操作面板展示本次使用的素材，允许移除素材、返回查看原文，再选择文字、图片、网页、图表、语音或文档。

「开始创作」会添加相连的新步骤并运行；「仅添加步骤」允许先安排流程。新步骤自动避开已有卡片。原有材料与作品保持原样，新方向作为独立分支保留。创建步骤和连接是一个可以撤销的操作。

创作方向作为独立分支保留。后续生成结果工作台还提供同一作品的版本列表与返回上一版；模型生成失败时，新增步骤仍可检查和重试。

### 2. 让模型获得正确的上下文

文字和已有结果继续作为文本输入，网页提供原 HTML，图表提供结构化数据。连接的手绘、图形、便签、线条和画框会形成整体画面，保留它们的空间关系；画框中的网页等内容也保留语义输入。图表生成可以接收这些视觉输入。

素材按钮可以查看实际连接的上游材料并返回原处。新入口运行后续步骤时，会使用上游已有内容，不主动重跑来源。取消发生在画布截图期间时，也会阻止后续模型调用。

范围说明：本轮处理的是连接到创作步骤的上下文。独立的「AI 绘图」能力仍沿用原有整页上下文；它的范围选择和操作预览列入后续工作。

### 3. 让录屏成为可继续使用的材料

录屏可以通过「转为创作画布」生成包含内容记录、转写和创作指令的项目。单句转写和单个章节也能直接生成独立创作画布，章节仅提取对应时间范围内的转写。

材料是可以编辑的普通文字卡片，同时保留来源录屏和时间位置。点击来源可返回分析页面并定位播放器。转换本身不调用模型；录屏中的事实内容可以先检查，再用于创作。

### 4. 收起干扰，修复细节

卡片标题收紧为 36 像素，图片、文字和图表获得更多空间。复制、下载、素材与继续创作等操作在选中时浮出卡片；已有结果默认作为画布内容呈现。桌面创作面板使用右侧独立栏，小屏使用下方面板，并跟随可用空间将当前素材保持在视野中。临时要求继续自动保留为浏览器草稿。

选中卡片后，可拖动左右端口连接已有素材或后续步骤，目标会高亮并显示预览线；拖到空白处可接续新步骤，也支持点按或键盘打开菜单。新连线标注素材含义；重复连接、循环和跨页面连接会被拦截。卡片和连线作为一次操作撤销，新步骤会避开已有内容。旋转及画框内卡片使用实际端口坐标；聚焦输入框不会单独滚动卡片图层。

运行中的路径以流动虚线标记，卡片显示等待、运行、失败或停止状态与耗时，顶部可查看本次步骤并定位内容。生成结果记录内容指纹、完成时间和耗时，刷新后仍可检查。素材或要求变化时，下游结果显示「需更新」，可只更新受影响分支；锁定结果继续复用。运行期间输入变化也不会把旧结果误标为最新。停止或失败保留已有作品，模型连接信息不进入这些记录。

离开内容区域后出现「回到内容」，有选区时优先找回选中的对象。新建步骤后切换视口会保留选中状态。

这些改动沿用现有中性配色、侧栏和深浅色模式。模型配置仍在设置中，仅由浏览器保存；本轮没有增加后端模型接口。

### 5. 在作品旁完成查看、修改和再次创作

文字、图片、网页使用统一的作品窗口。卡片标题、选区工具栏和已有作品的继续创作入口都能打开它；双击原生画布中的结果对象也可以进入。关闭窗口后返回当前作品，切换版本时画布跟随定位。

文字默认以 Markdown 阅读，编辑修改的是生成正文，原始要求继续保留。网页可以交互预览、切换桌面或手机尺寸、编辑 HTML 并检查实时预览；已有的脚本隔离与网络限制保持生效。编辑草稿按项目、页面和作品分别保存在浏览器，关闭窗口后可继续；其他页面更新原文时会保留草稿并提示冲突。修改可以保存、撤销，或直接「保存并创作」，让下一轮使用修改后的实际内容。

图片支持适应窗口、原始尺寸、缩放与拖动；放大后的拖动有边界，避免丢失图片。裁剪和旋转按原始像素生成本地 PNG，保存为相连的新图片，保留原图。复制操作写入实际图片，下载保留文件格式；文字和网页分别导出 Markdown 与 HTML。

再次创作默认沿用作品类型，也可转为文字、图片或网页。提交后只运行新分支，保留来源和已经完成的版本；完成后在同一窗口打开新作品，可以返回上一版或从版本列表切换。失败后修改要求并重试会复用未完成步骤；停止、关闭、重新打开均能找回未完成的创作。关闭窗口不会取消正在运行的请求，再次打开可看到进度并在完成后进入新版本。手机在作品和创作要求之间切换，操作按钮保持可达。

这落实了参考材料中「结果成为下一轮材料」的设计方向。当前版本列表是主动派生作品的导航，不记录每次文字编辑的快照，也不提供并排比较。

## 后续的优先顺序

以下属于产品建议，尚未实现。

1. **深化比较与标注。** 在现有版本列表之上，支持并排比较两个方向；文字批注和自由箭头需要可明确纳入某次请求的选区范围。
2. **深化直接编辑。** 网页已有 HTML 编辑与实时预览，后续可补充元素级调整与图表作品工作台；保持手工修改能够继续作为生成输入。
3. **约束绘图助手的操作范围。** 用选区或画框声明可操作区域，展示拟修改内容，允许逐次撤销；把助手的讨论放在独立的批注层。
4. **深化录屏与来源。** 支持连续选择多个片段、放入已有项目、定位原句和跨作品查看引用。本轮先把片段到新画布的链路打通。

不急于加入无限循环、自动运行整个画布、复杂变量系统、拟人化多助手或更多常驻面板。是否引入这些能力，应由真实任务中反复出现的需求决定。

## 用实际任务判断设计

- 从已有作品派生一个新方向，能否通过「选中 → 写要求 → 开始」完成？
- 用户能否在调用模型前确认使用哪些材料？
- 生成结果是否可以直接编辑，并继续作为下一步输入？
- 一个录屏片段能否成为创作材料，并回到原始时间点核对？
- 误操作后能否撤销，迷失视口后能否迅速返回？

## 完整作品示例 — 2026-11-03

查看了 [tldraw Computer](https://computer.tldraw.com/) 的 [Story Generator](https://computer.tldraw.com/t/m6rf2ckVFbRc7r7yZt9oGM) 与 [Invention Inventor](https://computer.tldraw.com/t/9sfvz9vrz5nUsFRspwTJXm)。它们把一个具体任务展开为多路输入、处理分支和下游作品；任务本身比单独介绍某种输出格式更容易理解。

画语据此将六个场景模板扩展为完整示例。用具体素材说明“从哪里开始”，通过共享输入与分支表达关系，再用文稿、插画和可操作网页说明“最后能得到什么”。示例内容均为作者编写，不标注虚构运行耗时或模型执行记录。官网预览与应用使用同一个目录；可以查看内容、回溯指令，再进入本地模板继续编辑。
