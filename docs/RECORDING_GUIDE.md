# 录屏与分析

## 录制或导入

从侧栏进入「录屏」，或在画布顶部选择录屏。选择屏幕、窗口或标签页，根据需要启用麦克风。浏览器和操作系统会请求对应权限；系统声音是否可选取决于系统、浏览器及共享来源。

录制时可以暂停、继续和停止。停止后先回看，再下载或保存。关闭回看窗口仍可返回继续保存；放弃需要确认。尚未保存的录制不会跨浏览器刷新保留，请先保存或下载。

已有音视频可直接导入。导入和保存后进入回看页面，检查声音和时长，再开始转写。

录屏列表自动显示视频中的真实画面作为封面，已有录屏也会显示，无需重新导入。横屏和竖屏都保留比例；纯音频显示音频封面。画面暂时无法读取时会显示「预览暂不可用」，仍可点击进入回看。封面在本地读取，不需要模型连接。

## 先转写，再整理

在设置中分别配置语音识别和文本生成。可以先选择「仅转写」检查识别内容，校对后再整理完整记录、章节与问答。语音识别的语言、发言人和时间戳由模型服务提供，识别错误需要人工校对。

长音轨优先通过本地 FFmpeg 分段处理。没有 FFmpeg 时使用浏览器解码，长视频会占用更多内存。单个附件上限 512 MB；具体可处理时长还取决于设备内存和识别服务限制。

## 回看与核对

- 点击句子、章节或问答时间，播放器定位到对应片段。
- 搜索转写定位关键词；使用上一句、下一句和倍速复查。
- 跟随播放只滚动转写列表，可以随时暂停跟随阅读。
- 校对保留时间戳；校对后原分析报告会失效，重新整理以保证文字一致。
- 手机在回看和内容之间切换，播放位置与倍速会在当前浏览器保存。

## 停止与继续

每个完成的识别分段与整理批次都会保存。应用内切换页面时任务继续；停止、请求失败或刷新后，可以继续已完成的部分。浏览器刷新会终止未完成请求，不会使本地服务在后台继续调用模型。

已有报告在新报告完成前仍可阅读。重新识别会重建对应的处理中间结果，因此先导出需要保留的转写和报告。

## 把片段变成作品

选一句、多句转写、章节或完整内容，使用「转为创作画布」。新画布会放入可编辑的文字素材，并保留来源与时间。先核对文字，再继续生成文章、图片或网页；来源链接可以返回原片段。

转换为画布本身不调用模型。你决定何时使用 AI、使用哪些片段以及要得到什么作品。

## 导出

原始录屏可下载，转写支持 TXT、SRT 与 VTT，内容整理支持 Markdown。仅返回文字的识别服务没有准确的逐句时间，字幕与定位能力会相应受限。
