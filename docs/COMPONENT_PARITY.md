# 组件输入与输出核对

本次以 MenteX 旧版前端 `app/frontend/src` 下的实际组件事件、执行 Hook 和 API 参数构造代码为依据。表中旧版源码位置均相对于这个目录记录。先检查组件实际调用的函数，再检查公共工具函数，避免把未调用的旧逻辑当作组件行为。

## 逐项结果

| 组件 | 接收的内容 | 生成或保存的内容 | 向后提供的内容 | 旧版依据与本次处理 |
| --- | --- | --- | --- | --- |
| 创作指令 | 自身指令，以及前置文字、图片、语音、网站、文件或画框快照；支持联网搜索 | `result`、`name`、`description` | 最新生成的正文；无后续组件时建立相连的文本组件 | `Components/shapes/InstructionShape/InstructionComponent.tsx:90`、`utils/componentAPI.ts:255`。保留自身指令，补齐图片说明和文件正文的传入规则。 |
| 文本 | 手动输入；或各前置组件的文字输出，网站优先取摘要、图片取说明、画框取文字摘要 | 前置内容按单个换行拼接，写入 `text` 与 `result`；没有有效前置内容时保留当前正文 | 正文 | `Components/shapes/TextShape/AITextComponent.tsx:151`。修正为替换正文，取消追加自身旧正文。 |
| AI 绘图／图片 | 上传图片；运行生成时接收前置指令、文本、图片或画框快照 | 图片 `src`、说明 `result`、名称与描述、图片比例 | 给多模态组件传图片及说明；给文本组件传说明 | `Components/shapes/ImageShape/AIImageComponent.tsx:154`、`utils/componentAPI.ts:406`。有前置内容时重新生成；没有前置内容或要求时沿用现图。恢复旧比例映射，移除独立输入框。 |
| 语音 | 上传音频；或前置组件的文字输出，画框按快照传入 | 上传时立即识别，保存原音频 `src` 与转写 `result`；生成时保存音频、朗读正文、名称和描述 | 音频和文字；文字接收方读取转写或朗读正文 | `Components/shapes/SpeechShape/SpeechComponent.tsx:150`、`utils/componentAPI.ts:530`。恢复上传后立即转写，移除独立输入框和额外转写按钮；有前置输入时不因曾上传而跳过生成。 |
| 网站 | 前置组件的文字、参考图片或画框快照 | 调用网页生成接口，保存相同的 `htmlContent` 与 `result`，以及名称、描述；用 iframe 预览 HTML | 给文本组件提供摘要；其他文字接收方读取网页正文 | `Components/shapes/WebsiteShape/WebsiteComponent.tsx:636`、`utils/componentAPI.ts:600`。移除独立输入框，只按前置内容运行，保留预览、刷新、复制和下载。旧版也调用网页生成接口，并非直接把任意上游文本当作 HTML。 |
| 文件 | 上传文档后立即解析；或前置组件的文字输出，画框按快照传入 | 文件地址、正文、文件名、扩展名、大小、名称与描述 | 给指令组件传文件地址和正文；给文字接收方传正文 | `Components/shapes/FileShape/FileComponent.tsx:340`、`utils/componentAPI.ts:685`。移除独立输入框，补齐描述；有前置输入时不因曾上传而跳过生成。 |
| 图表 | 前置组件的 `result`／`text`；无前置内容时兼容已有项目保存的文本 | 生成可编辑的思维导图或流程图；结构存入 `chartData`，标题存入 `result`，摘要存入 `description` | 标题文字，与内部图表 JSON 分开 | `Components/shapes/ChartShape/AIChartComponent.tsx:85`。取消追加旧输入；按旧接口处理文本或 JSON；编辑图表只更新结构，切换类型时保留现图并按实际结构渲染。移除独立输入框。 |
| 运行 | 用户点击后触发后续组件；下游可越过它读取更前面的材料 | 不生成正文 | 执行触发；它本身不替代数据源 | `Components/shapes/StartShape/StartComponent.tsx:31`、`utils/connectionParser.ts:89`。恢复中途暂停：被上游触发后停在此处，等待用户点击；允许连入运行节点。 |
| 外部链接 | URL，无前置执行输入 | 嵌入页面，获取并保存 HTML、标题、描述；`result` 依次采用 HTML、标题、URL | 保存的网页内容可作为材料读取；不触发 AI 执行链 | `Components/shapes/InteractiveWebShape/InteractiveWebComponent.tsx:75`。恢复已有 URL 首次自动获取，补齐标题回退、外置帮助和锁定；不提供 AI 运行按钮或输入连线口。 |
| 画框 | 框内画布内容 | 需要被 AI 读取时生成一张整体快照 | 对 AI 接收方传一张图片；文本接收方读取画框摘要或名称 | `utils/frameAPIHelpers.ts:105`。运行连线不再同时拆出框内文字，避免重复输入。 |
| AI 解答 | 自身指令与自身选框内的原生图形、文字、快照 | Agent 操作直接修改画布，保存完成状态 | 不作为普通 AI 组件的输入／输出中继 | `Components/shapes/DrawShape/DrawComponent.tsx:90`。恢复选框范围，移除整张画布和连线内容对请求的替代；框外变化不再影响此组件的内容状态。 |

## 组件工具与位置

工具直接对照旧版组件的 JSX 还原，常驻组件内部，不依赖选中状态。

| 组件 | 工具与位置 |
| --- | --- |
| 创作指令 | 左下角联网搜索开关，距内容区左侧和底部各 8 像素；正文底部预留按钮空间。 |
| 文本 | 正文编辑区，无额外工具条。 |
| 图片 | 左下角上传、下载，右下角带方向图标的比例菜单；距内容区边缘 12 像素。 |
| 语音 | 左下角上传、下载，右下角上传／生成状态。 |
| 网站 | 有 HTML 时，左下角显示全屏查看、刷新、复制、下载。 |
| 文件 | 左下角上传，有正文时提供复制，有可下载文件时提供下载；中央显示文件名与大小。 |
| 图表 | 右下角带类型图标的思维导图／流程图菜单，距内容区边缘 8 像素。 |
| 外部链接 | 有 URL 时，左下角显示全屏查看、刷新；不显示连接点工具栏。 |
| AI 解答 | 透明选框下方 64 像素处，居中显示指令输入与提交按钮。 |
| 运行 | 中心的运行按钮。 |
| 画框 | 使用画板原生调整面板，无附加组件工具条。 |

选中组件后的外部操作浮层、底部素材／查看作品／继续创作工具条、选区创作面板及其草稿恢复逻辑均已删除。

## 公共行为

- 组件标题栏已移除展开按钮、更多菜单和清除生成结果操作，保留帮助、外置锁定与运行。
- 下游执行时重新读取已保存的最新前置内容；锁定组件沿用已有结果。
- 上传音频或文档完成识别／解析后，才整体替换组件内容；失败时保留已有内容。
- 浏览器模型连接的保存位置继续遵循项目约定。模型调用失败按真实错误处理，已有成功结果保留。分支汇合只执行一次，停止操作会取消未完成的请求。

## 验证

`workflow/execute.test.ts` 覆盖前置输入选择、文本替换、网站生成及输出、图片生成与比例、音频／文件传递、图表结构和摘要、画框快照、运行节点暂停、AI 解答范围与外部链接的执行边界。`workflow/uploads.test.ts` 覆盖音频上传即转写、失败不返回替换内容、文档解析与图片上传。
