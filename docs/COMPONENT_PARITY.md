# 组件输入与输出核对

本页记录各组件接收、保存和传递的内容，以及工作流中的特殊行为。

## 逐项结果

| 组件 | 接收的内容 | 生成或保存的内容 | 向后提供的内容 | 运行规则 |
| --- | --- | --- | --- | --- |
| 创作指令 | 自身指令，以及前置文字、图片、语音、网站、文件或画框快照，支持联网搜索 | `result`、`name`、`description` | 最新生成的正文 | 无后续组件时建立相连的文本组件。 |
| 文本 | 手动输入或前置组件的文字输出，网站优先取摘要、图片取说明、画框取文字摘要 | 按单个换行拼接前置内容并替换 `text` 与 `result` | 正文 | 没有有效前置内容时保留当前正文。 |
| AI 绘图／图片 | 上传图片，或接收前置指令、文本、图片和画框快照 | 图片 `src`、说明 `result`、名称与描述、图片比例 | 给多模态组件传图片及说明，给文本组件传说明 | 有前置内容时生成图片，缺少前置内容和创作要求时沿用现图。 |
| 语音 | 上传音频，或接收前置组件的文字输出和画框快照 | 上传时立即转写，保存原音频 `src` 与转写 `result`。生成时保存音频、朗读正文、名称和描述 | 音频和文字。文字接收方读取转写或朗读正文 | 已上传音频的组件仍可使用前置输入生成新音频。 |
| 网站 | 前置组件的文字、参考图片或画框快照 | 调用网页生成接口，保存相同的 `htmlContent` 与 `result`，以及名称和描述 | 给文本组件提供摘要，其他文字接收方读取网页正文 | 在 iframe 中预览 HTML，支持刷新、复制和下载。 |
| 文件 | 上传文档，或接收前置组件的文字输出和画框快照 | 文件地址、正文、文件名、扩展名、大小、名称与描述 | 给指令组件传文件地址和正文，给文字接收方传正文 | 上传后立即解析。已上传文档的组件仍可使用前置输入生成文件。 |
| 图表 | 前置组件的 `result` 或 `text`，无前置内容时可使用已有项目保存的文本 | 生成可编辑的思维导图或流程图，结构存入 `chartData`，标题存入 `result`，摘要存入 `description` | 标题文字 | 编辑图表只更新结构，切换类型时保留现图并按实际结构渲染。 |
| 运行 | 用户点击 | — | 触发后续组件，下游可越过运行节点读取更前面的材料 | 上游触发后在此暂停，等待用户点击继续。 |
| 外部链接 | URL | 嵌入页面并保存 HTML、标题和描述，`result` 依次采用 HTML、标题、URL | 保存的网页内容可作为材料 | 已有 URL 首次打开时自动获取页面内容。作为材料节点使用。 |
| 画框 | 框内画布内容 | 按需生成一张整体快照 | 给 AI 接收方传图片，给文本接收方传画框摘要或名称 | 以整个画框为素材。 |
| AI 解答 | 自身指令与选框内的原生图形、文字和快照 | 直接修改画布并保存完成状态 | — | 选框决定请求使用的画布内容。 |

## 组件工具与位置

组件工具常驻卡片内部。

| 组件 | 工具与位置 |
| --- | --- |
| 创作指令 | 左下角联网搜索开关，距内容区左侧和底部各 8 像素；正文底部预留按钮空间。 |
| 文本 | 正文编辑区，无额外工具条。 |
| 图片 | 左下角上传、下载，右下角带方向图标的比例菜单；距内容区边缘 12 像素。 |
| 语音 | 左下角上传、下载，右下角上传／生成状态。 |
| 网站 | 有 HTML 时，左下角显示全屏查看、刷新、复制、下载。 |
| 文件 | 左下角上传，有正文时提供复制，有可下载文件时提供下载；中央显示文件名与大小。 |
| 图表 | 右下角带类型图标的思维导图／流程图菜单，距内容区边缘 8 像素。 |
| 外部链接 | 有 URL 时，左下角显示全屏查看、刷新；不显示连接点工具栏。 |
| AI 解答 | 透明选框下方 64 像素处，居中显示指令输入与提交按钮。 |
| 运行 | 中心的运行按钮。 |
| 画框 | 使用画板原生调整面板，无附加组件工具条。 |

选中组件后的外部操作浮层、底部素材／查看作品／继续创作工具条、选区创作面板及其草稿恢复逻辑均已删除。

## 公共行为

- 组件标题栏已移除展开按钮、更多菜单和清除生成结果操作，保留帮助、外置锁定与运行。
- 下游执行时重新读取已保存的最新前置内容；锁定组件沿用已有结果。
- 上传音频或文档完成识别／解析后，才整体替换组件内容；失败时保留已有内容。
- 浏览器模型连接的保存位置继续遵循项目约定。模型调用失败按真实错误处理，已有成功结果保留。分支汇合只执行一次，停止操作会取消未完成的请求。

## 验证

`workflow/execute.test.ts` 覆盖前置输入选择、文本替换、网站生成及输出、图片生成与比例、音频／文件传递、图表结构和摘要、画框快照、运行节点暂停、AI 解答范围与外部链接的执行边界。`workflow/uploads.test.ts` 覆盖音频上传即转写、失败不返回替换内容、文档解析与图片上传。
