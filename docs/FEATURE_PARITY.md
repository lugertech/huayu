# 功能迁移对照

核对日期为 2026-10-24。核对对象为 MenteX 前端及 tpk-admin 的 `MenteX` 控制器、服务、提示词和录屏分析任务，见[来源仓库与固定版本](./LICENSING.md#两个来源仓库)。范围是 MenteX 产品及其必要后端。tpk-admin 中独立的教育管理、支付、账户管理等系统不作为本项目入口。

## 工作流与白板

## 录屏与分析

原行为重点参考 MenteX 的 `useScreenRecording.ts`、`RecordingAnalysisPage.tsx`、`RecordingsPage.tsx`，以及 tpk-admin 的 `ScreenRecordingController.php`、`Jobs/ScreenRecordingAnalysisJob.php`。

| 原功能 | 本地实现与本轮补齐 |
| --- | --- |
| 屏幕/窗口/标签页及麦克风录制、暂停和继续 | 保留 MediaRecorder 录制与声音混合；下载或保存本地录屏，导入现有音视频 |
| 云存储中的音频提取 | Rust 调用本地 FFmpeg/ffprobe；每次最多读取五分钟的 16 kHz 单声道 WAV，限制并行进程与超时；缺少工具时回退浏览器解码 |
| 识别、发言人和时间戳 | 浏览器直接请求已配置识别服务；按段保存文字、时间和发言人；兼容旧转写结构 |
| 详细内容记录、章节和问答 | 补上完整内容记录；长转写分批整理，再合并报告；约束时间来自原转写，问答只提取原文实际内容 |
| 后台分析状态与结果持久化 | 浏览器内导航不停止任务；每个已完成的音轨段和报告批次都保存检查点；取消、失败或刷新后继续已完成的进度，上一份报告保持可读 |
| 章节、逐句和问答跳转 | 保留时间定位、上一句/下一句和倍速；新增转写搜索、跟随播放与保留时间戳的校对；校对后清除过期报告 |
| 结果与录屏下载 | 原始格式下载；TXT 转写、SRT/VTT 字幕和 Markdown 分析报告，导出隐藏处理中间结构 |

## 按要求移除和调整

- 移除登录、注册、用户、会员、积分、充值和支付链路。
- 项目、模板、附件、录屏、转写及报告保存在本地；没有云存储上传、云分析队列或模型配置保存接口。
- 模型地址、名称、密钥、音色与搜索配置只保存在浏览器，不进入项目、模板和导出文件。远程模型仅在用户使用相应 AI 能力时由浏览器连接；需要推理内容也留在本机时配置本机服务。
- 原云数据库的数据不在源码中，不自动访问或导入；保留兼容项目文件读取。
- 原模型供应商的具体能力、逐句时间戳和 OCR 不由兼容客户端统一保证。现有本地文档解析不包含扫描 PDF 的 OCR。真实模型与系统录屏授权的验证边界见 [验证记录](./VERIFICATION.md)。

## 界面

统一 Codex 式侧栏、最近项目和底部设置。项目首页使用紧凑入口；白板使用可拖拽的左侧组件栏和底部工具；录屏分析采用播放器/转写与阅读区并排布局。沿用 shadcn/Base UI 中性色，支持深色、浅色和跟随系统。内部协议、迁移标记和处理检查点不进入面向用户的页面。

## 素材库交互补齐 — 2026-11-03

按用户提供的 pure-design 本地工作区迁移。其 `DesignAssetPicker.tsx` 委托给 `FabricMaterialInsertDrawer.tsx`；管理界面实际位于 `features/asset-library/AssetExplorer.tsx` 与 `AssetFolderTree.tsx`。本轮直接复制管理器、文件夹树和文件夹图标，再适配本地接口；插入面板沿用原实现的分组筛选树及按图片比例分配瀑布流列的算法。来源工作区 HEAD 为 `dcd4f46`，迁移包含该工作区当时的现有代码。

| 来源操作 | 画语实现 |
| --- | --- |
| 文件夹树、目录卡片、路径导航 | `AssetFolderTree.tsx`、`AssetBrowser.tsx`；本地 UUID、嵌套目录与当前分组数量 |
| 素材、文件夹与空白区域右键菜单 | 打开、重命名、移动、删除、新建子文件夹和刷新；补充插入、下载与恢复入口；支持菜单键盘操作 |
| 图片拖到树节点或目录卡片 | 整卡跟随指针、树区域缩小预览、落点高亮；移动后同步列表与数量，也可拖回根目录 |
| 批量上传对话框 | 队列缩略图、逐项状态、取消待上传文件、清空、开始上传与关闭 |
| ViewerJS 图片预览 | 上一张、下一张、缩放、原始尺寸、旋转、重置与 Esc 关闭；预览变换不改写原文件 |
| 插入面板分组与图片选择 | `AssetFolderFilter.tsx`；全部图片、分组树筛选、搜索排序、等比例瀑布流、选择后插入和双击插入 |
| 拖入画布 | 原生 Excalidraw 图片、松手落点、保留比例、单步撤销；保留素材库原图，面板内部拖放不触发画布插入 |
| 本地版已有回收站 | 图片删除改为移入回收站，可恢复；删除文件夹将内容移到上一级；不破坏已有画布图片 |

接口适配在 `features/asset-library/library-api.ts`。目录元数据和图片保存在本地实例；账号、配额、云端公开图库和审核流程不纳入本地版本。交互文案中英文适配随素材功能按需加载，ViewerJS 1.11.8 的 MIT 许可进入依赖清单和发行包。
