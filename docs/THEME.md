# 界面配色与层级

页面参考 Manus 的浅灰与暖白配色。浅色基础色从参考截图取样：侧栏 `#F0F0F0`、内容底色 `#F8F8F7`、侧栏选中行 `#E5E5E5`、品牌深色 `#34322D`、正文 `#1A1A1A`。深色模式按相同的中性色温与层级适配。主要操作使用深色按钮，悬停与选中状态通过灰阶区分。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 主要操作 | `#34322D` | `#E6E4DE` |
| 主按钮文字 | `#FFFFFF` | `#26241F` |
| 主色悬停 | `#262521` | `#F4F2ED` |
| 页面底色 | `#F8F8F7` | `#191919` |
| 卡片 | `#FFFFFF` | `#242424` |
| 侧栏底色 | `#F0F0F0` | `#212121` |
| 侧栏选中行 | `#E5E5E5` | `#303030` |
| 普通悬停 | `#EAEAE7` | `#333333` |
| 工具选中底色 | `#E7E5E0` | `#373633` |
| 正文 | `#1A1A1A` | `#ECEBE8` |
| 辅助文字 | `#706D67` | `#A5A29C` |
| 边框 | `#E2E2E2` | `#353535` |
| 焦点提示 | `#6D6961` | `#AAA69E` |

侧栏保持低对比度，当前导航通过背景和小图标区分。首页将新建操作放在页首，左侧展示最近画布的预览与继续入口，右侧提供四个示例入口；项目列表保留搜索、复制、重命名与导入操作。避免用成片的强调色代替布局层级。

颜色通过 `apps/web/src/main.css` 的语义变量管理。普通悬停使用 `accent`，工具选中使用 `brand-soft`，两者分别定义。Base UI 组件与 Excalidraw 工具界面共享变量，包括滑块、焦点和属性面板；作品内的文字、图片和网页使用各自的内容配色。卡片标题、边框与占位样式同步到预览和导出。

画布预览按最长边 960 像素生成，缩放最多为 2 倍，并限制图片大小。卡片导出保留标题、图标、空白提示和可辨认的边框；图片读取完成后再生成预览。打开画布时检查预览版本、分辨率与文档版本，自动更新旧预览。预览刷新只更新缩略图，不修改文档版本或编辑时间。

画布卡片使用 36 像素的紧凑标题，已有作品的查看入口保持可见，其他次要操作在悬停、键盘聚焦或选中时出现。底部操作栏仅在选中时浮出，保留正文面积。静态导出同步采用紧凑标题和更大的图片、图表区域。运行路径使用主色，错误使用错误色；过期提示以小图标和文字呈现，避免给整张卡片铺设状态色。减少动态效果的系统设置会关闭连线路径动画。

作品窗口沿用相同中性色：阅读区域以内容为主，桌面创作要求放在右侧 320 像素面板，手机切换作品与要求。文字阅读使用 16 像素正文和受限行宽；图片使用低对比度背景，网页保留作品自身配色。提交新版本等主要操作使用实心深色按钮；深色模式使用浅色按钮。

受测主按钮文字对比度为浅色 12.80:1、深色 12.19:1。正文、辅助文字、侧栏导航、工具选中态和文本选区等受测组合最低为 4.53:1。此结果仅覆盖指定颜色组合，不等同于全站无障碍合规审计。
