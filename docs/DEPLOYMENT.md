# 部署与备份

## 本机运行

当前版本默认面向个人本机使用。安装方式见 [快速开始](./GETTING_STARTED.md)。发布候选验证范围见 [发布清单](./RELEASE.md)，尚未经过验证的平台不作为已支持承诺。

构建和运行：

```sh
vp install --frozen-lockfile
vp run build
vp run start
```

Rust 服务提供本地 API 和前端文件，地址为 `http://127.0.0.1:5858`。更换版本时先停止旧进程并备份数据，再构建和启动新版本。

## 配置

可复制 `.env.example` 为 `.env`；启动脚本会读取根目录的 `.env`。不要在其中添加模型密钥。

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `HUAYU_HOST` | `127.0.0.1` | 监听地址 |
| `HUAYU_PORT` | `5858` | 服务端口 |
| `HUAYU_DATA_DIR` | `var/dev` | 数据库与附件目录 |
| `HUAYU_WEB_DIR` | `apps/web/dist` | 前端构建目录 |
| `RUST_LOG` | `huayu_server=info,tower_http=warn` | 本地日志级别 |

相对路径以仓库根目录为基准。直接运行二进制时，需由调用环境设置变量，并确保工作目录或路径正确。

开发启动器和 Web 代理共同使用 `HUAYU_HOST`、`HUAYU_PORT`：根目录 `.env` 中的值优先，其次是进程环境，最后使用上表默认值。修改后重启开发进程，`/api`、`/uploads` 和 WebSocket 代理会自动跟随。开发端口需为 1 至 65535；监听所有地址时，代理使用对应的本机回环地址连接。

模型连接属于浏览器来源，端口变化后需要重新配置。静态文件可以复制，浏览器中的配置与草稿不会随服务目录自动移动。

## 局域网协作

默认 `127.0.0.1` 只能供本机访问。让同一局域网内的其他电脑参与协作时，在提供画语服务的电脑上：

1. 先按上文完成构建，停止旧服务。
2. 在根目录 `.env` 中，将 `HUAYU_HOST` 改成这台电脑当前的具体局域网 IP，例如下列示例；保留原来的数据目录。
3. 运行 `vp run start`，并在系统防火墙中仅允许需要的可信设备访问该端口。
4. 双方都通过 `http://192.168.1.20:5858` 打开画语。将示例 IP 换成服务电脑的实际地址；在这个地址打开原画布后复制协作链接。

```dotenv
HUAYU_HOST=192.168.1.20
HUAYU_PORT=5858
HUAYU_DATA_DIR=var/dev
HUAYU_WEB_DIR=apps/web/dist
```

使用具体 IP，不要将它换成 `0.0.0.0`：当前服务会校验访问地址，通配监听不代表允许任意地址。不要把服务转发到公网。参与者共用这个实例，不能各自启动一个服务再期待项目自动互通。服务电脑的 IP 改变后，需要调整配置并重新复制链接。

共享画布的详细步骤见 [多人协作](./USER_GUIDE.md#多人协作)。模型服务也必须能从执行者的浏览器访问；其他电脑上的 `localhost` 不会指向服务电脑。局域网 HTTP 可用于画布协作，但浏览器录屏等需要安全上下文的功能仍需本机来源或合适的 HTTPS 部署。

## 备份

保存以下两部分：

1. `HUAYU_DATA_DIR/huayu.sqlite3` 数据库。
2. `HUAYU_DATA_DIR/assets/` 全部附件。

最简单的方式是先停止服务，再复制整个数据目录。运行中备份需使用 SQLite backup API，并另外保留附件；不要只复制正在写入的 `.sqlite3` 文件而忽略 WAL。模型配置与未保存草稿在浏览器中，需要在新浏览器重新配置。

恢复时先停止服务，将数据库和附件放回同一数据目录，再用对应版本启动。先在独立目录核对项目、录屏、附件和导出，确认后切换日常使用的数据目录。

项目导出适合单项目迁移，不能代替录屏库和整个实例的备份。

## 访问边界

本机管理端保留工作区权限，其他设备通过有效协作链接编辑指定画布。协作者使用独立布局，不能浏览项目列表、全局素材库或录屏，也不能管理项目和分享链接。管理端根据服务机器的连接来源识别，不提供账号或租户体系；在服务机器上直接访问工作区仍是管理端。

开发代理已透传来源地址。部署其他反向代理时，必须正确传递可信的 `X-Forwarded-For`，避免将远端请求当成本机请求。不要直接将应用 API 暴露到公网；公网部署仍需要外部认证、TLS、访问控制及维护。
