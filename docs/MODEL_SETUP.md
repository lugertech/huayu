# 模型连接

在侧栏底部打开「设置 → 模型连接」。配置只保存在当前浏览器，点击「保存设置」后生效。取消会保留原配置；清除浏览器站点数据会删除连接信息。

## 配置对应能力

不需要一次配全。未配置的能力只影响用到它的 AI 操作，白板绘制、手动编辑、素材上传、项目保存与导出、录制和回看仍可使用。

| 配置情况 | 可使用的功能 |
| --- | --- |
| 未配置任何 AI | 白板、已有作品编辑、素材管理、项目导入导出、录制与回看 |
| 只配置文本生成 | 纯文字创作、网页、文件、自然语言图表，以及已有转写的内容整理 |
| 只配置语音识别 | 音频和录屏的「仅转写」 |
| 输入包含图片或画布截图 | 相关创作还需配置图像理解；图片生成使用独立的图片模型 |
| 开启联网搜索 | 该条创作指令还需配置联网搜索；关闭后可继续普通创作 |

「已填写 · 待测试」只表示连接信息完整。未配置时，相关操作会指出缺少哪项，并提供对应设置入口；不会改用其他模型服务。录屏处理会在开始前检查本次所需的连接，保留已有转写与报告。

| 能力 | 需要的接口 | 用途 |
| --- | --- | --- |
| 文本生成 | OpenAI 兼容 `chat/completions` | 写作、网页、图表、文件与内容整理 |
| 图像理解 | 支持图片消息的 `chat/completions` | 读取参考图片与画布内容 |
| 图片生成 | `images/generations`，参考编辑需 `images/edits` | 生成新图片、基于图片修改 |
| 语音合成 | `audio/speech` | 将文字转为音频 |
| 语音识别 | `audio/transcriptions` | 音频与录屏转写 |
| 联网搜索 | Tavily 或 Brave Search | 为明确启用搜索的任务提供资料 |

地址填写 API 根地址，不要重复添加具体接口路径。模型名称不是显示昵称，需要使用服务实际识别的标识。没有密钥的本机服务可以留空；远程服务使用你自己的有效密钥。

部分能力可复用文本生成的地址与密钥，模型名称、音色和识别格式仍分别保留。服务是否支持图片编辑、特定尺寸、音色或逐句时间戳，由该服务决定；接口兼容不代表所有能力相同。

## 本机与远程服务

选择本机模型时，请先启动服务，并允许页面来源的浏览器请求。开发页面来源是 `http://127.0.0.1:5173`，构建后通常是 `http://127.0.0.1:5858`。不同端口的浏览器设置相互独立。

浏览器直接向配置的模型发送所选素材，画语的数据服务不代理模型调用。使用远程模型时，所选文字、图片或音轨会发给该服务；需要推理内容也留在本机时，使用本机模型。

新任务的默认输出语言随界面语言选择，提示词中明确指定的其他语言优先。切换界面不会翻译已有作品、转写或报告。长录屏整理任务开始后保持原输出语言，避免同一份新报告在处理中混用语言。

## 连接测试

可以先测试当前填写的连接，点击「保存设置」后才供后续任务使用。修改字段或切换能力会取消旧测试。

- 文本生成：发送一条简短文字请求；图像理解使用同样的文字探测，图片输入仍需实际验证。
- 图片生成、语音合成、语音识别：只检查服务与模型列表，不生成收费内容。找到模型时仍会提示能力尚待实际验证；服务不提供列表时也不会误报测试成功。
- 联网搜索：执行一次简短搜索。文字和搜索测试可能按服务商规则计费。

连接测试最长等待 15 秒。生成请求有等待上限，并支持手动取消；失败后不会在后台自动重复生成。更新连接后，可从原步骤重试。

常见错误：

- 无法连接：检查模型服务是否启动、地址是否正确、是否允许当前页面跨域请求。
- 模型未找到：核对服务中的实际模型标识。
- 密钥无效或过期：更新对应能力的 API 密钥。
- 额度不足或请求受限：检查服务商余额与用量，稍后重试。
- 文字可用但图片失败：分别确认图像理解、图片生成和参考编辑接口。
- 识别没有句子时间：更换支持时间戳的识别格式和模型；仅返回文字的服务不能恢复准确逐句时间。
- HTTPS 页面连接 HTTP 服务受阻：检查浏览器的混合内容限制，优先在本机来源使用，或为服务提供 HTTPS。

不要为了排障把密钥发到公开反馈中，也不要将完整浏览器存储粘贴给他人。
