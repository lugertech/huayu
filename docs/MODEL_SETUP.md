# 模型与工具

从侧栏打开「设置 → 模型与工具」。五个分类分别显示「未配置」「已关闭」「待验证」「已验证」或「验证失败」。配置只保存在当前浏览器，点击「保存设置」后供新任务使用。保存后可以在弹窗里继续编辑，底部会显示「所有更改已保存」。清除站点数据会删除配置。

按任务配置所需分类。纯文字创作、网页、文件、图表和已有转写的整理需要语言模型。「仅转写」需要语音识别。白板绘制、素材上传、手动编辑、保存、导出、录制和回看可以直接使用。

| 分类 | 设置项 |
| --- | --- |
| 语言模型 | 点击「添加模型」，填写 API 地址，选择 Chat Completions 或 Responses，按需填写密钥和显示名称。点击「获取可用模型」后搜索并勾选模型，再点击「更新列表」。也可以直接填写模型 ID。 |
| 图片生成 | 为 GPT Image 或 Seedream 填写 API 密钥和模型 ID。Seedream 也接受火山方舟推理接入点 ID。至少开启一项才能生成图片。两项都开启时，可设置默认服务。 |
| 语音合成 | 填写阿里云百炼地域、业务空间 ID、API 密钥和音色。 |
| 语音识别 | 填写阿里云百炼地域、业务空间 ID 和 API 密钥。同一业务空间可与语音合成复用配置。 |
| 联网搜索 | 填写 Tavily API 密钥并开启服务。在画布指令上开启联网搜索后，才会在此次任务中发出查询。 |

填写服务提供的 API 根地址。例如，OpenAI 官方服务使用 `https://api.openai.com/v1`，本机服务可以使用 `http://localhost:11434/v1`。使用免密服务时可留空 API 密钥。

同一连接可以一次加入多个模型。重新打开可用模型列表时，已添加的模型会勾选。更新列表只影响服务本次返回的模型，手动添加的目录外模型会保留。

画布在「运行」旁显示当前模型。「语言模型」和「图片生成」可以分别选择。开启选模菜单的「图像理解」筛选，可以选择已通过图片测试的模型，用于含参考图或画布截图的语言任务。缺少所需设置时，可以从提示直达相应分类。

## 测试配置

可以先测当前输入，再点击「保存设置」。修改接口类型、地址、密钥、模型或音色后，重新测试受影响的操作。

- 填好语言模型配置后可以展开「测试连接」。「测试文字」发送短文字请求。「测试图片」发送一张在本地生成的小图，并核对模型读出的信息。
- 图片生成分别测试文生图和参考图。测试使用画语提供的样例。
- 「试听音色」合成一小段音频。语音识别测试发送一段样例录音，并检查返回的文字和时间戳。
- 联网搜索测试执行一条短查询，并检查返回的搜索结果。

测试会发出实际请求，可能消耗服务额度。遇到连接失败时，检查服务地址、网络和跨域访问。遇到权限或额度错误时，检查对应服务的账号。文字和图像理解分别验证。重新设置后可从失败的操作重试。

## 迁移已有设置

已有文本生成和图像理解连接会作为 Chat Completions 模型导入，保留各自的选择。保存的官方 GPT Image 和 Tavily 连接也可以继续使用。重新测试需要用到的操作。

旧版 OpenAI 兼容语音服务、Brave Search 和自定义图片或搜索网关的浏览器配置保留在旧版记录中。使用这些分类时，请填写阿里云百炼、GPT Image、Seedream 或 Tavily 的对应凭证。

## 浏览器连接

浏览器直接向所选服务发送本次任务的素材。服务需要允许当前页面来源，开发页面通常是 `http://127.0.0.1:5173`，构建后通常是 `http://127.0.0.1:5858`。不同来源各自保存设置。HTTPS 页面连接 HTTP 服务时，请使用浏览器允许的本机来源或为服务设置 HTTPS。

录屏转写分段提交音轨，支持句子定位。处理失败可以从已保存的进度继续。生成和转写内容按画语的项目规则保存，服务地址、密钥和模型选择只保存在浏览器。切换界面语言时，已有作品、转写和报告保留原文。

官方文档提供可用模型、音色和参数。 [OpenAI Responses](https://developers.openai.com/api/docs/guides/migrate-to-responses)、[GPT Image](https://developers.openai.com/api/docs/guides/image-generation)、[Seedream](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)、[阿里云百炼语音合成](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)、[阿里云百炼语音识别](https://help.aliyun.com/zh/model-studio/qwen-audio-asr-http-api)、[Tavily](https://docs.tavily.com/documentation/api-reference/endpoint/search)。
